JWT Decoder

Paste a JSON Web Token and see its header and payload decoded into readable JSON. This decodes only — it doesn't verify the signature.

jwt

Decoding happens entirely in your browser — the token never leaves your machine. Since JWTs are only Base64-encoded (not encrypted), this doesn't check the signature or prove the token is valid.
